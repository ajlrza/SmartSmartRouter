# SmartSmartRouter

## Overview
SmartSmartRouter is a combined project that's composed of 6 AI architecture implementations and 1 custom mini-neural network trained to classify and determine which AI architecture is capable of handling given multimodal inputs

A Smart Router which is smart from dynamic routing but is also smarter becaue it's an AI model

## Requirements
To run this model, ensure you have the following installed:
* Python 3.7+
* PyTorch (`torch`, `torchvision`)
